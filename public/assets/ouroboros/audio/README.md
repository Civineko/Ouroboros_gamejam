# Boss runtime audio

This directory contains only files loaded by the packaged game.

- `music/bgm_boss_devourer.mp3` is the supplied `The_Hunter_s_Last_March.mp3` and starts on `boss-spawned`.
- `sfx/gameplay/sfx_boss_charge.mp3` is the supplied `大狗大狗叫叫叫-单句.mp3` and plays once on `boss-charge`.
- The spawn, core-hit, and defeat WAV cues are deterministic procedural assets generated by `scripts/generate_boss_sfx.py`.

The two supplied recordings are included as project-owner-provided material. Confirm their redistribution rights before a public store release. Runtime paths, mix levels, and loop settings are defined only in `src/features/ouroboros/phaser/audio/audioCatalog.ts`.
